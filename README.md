# My Study

개인 학습을 위한 웹 기반 학습 플랫폼입니다.

## Features

- 카테고리별 학습 콘텐츠 관리
- 과목 및 교재별 학습
- 영어 본문 및 한국어 번역
- 단어장 및 동사 활용
- TTS 및 오디오 재생
- 연습 문제 및 오답 복습
- 학습 콘텐츠 암호화
- 모바일 및 데스크톱 반응형 UI

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Crypto API
- Node.js
- GitHub Actions
- GitHub Pages
